# 主体提取

当用户**明确要求**从图片中提取主体、去除背景、或抠图时，使用此技能。

## When NOT To Use

**CRITICAL**: 不要因为用户上传了图片就主动触发主体提取。

- 用户只发图片没有文字指令时，**不要**使用此技能。先分析图片并询问用户想做什么。
- 用户说"生成图片"、"画一张"等创作意图时，使用 `generate_image`，不是此技能。
- 用户发图片并问"这是什么"、"描述一下"时，正常回答，不要提取主体。
- 只有用户**明确表达**提取/去背景/抠图意图时才触发。

## 触发条件

用户**明确说出**以下意图时触发：
- "提取主体"、"提取图像主体"、"把主体抠出来"
- "去背景"、"去掉背景"、"去除背景"
- "抠图"、"分离主体"

不确定用户意图时，先问用户想做什么，**不要**默认当作提取意图。

## 模式选择（必须先问用户）

**当用户要求提取主体时，必须先询问：**

> 用本地分割还是 AI 生成来提取主体？

- **本地分割**：使用 `segment_subject` + `apply_mask` 两步流程，通过本地分割服务精确提取主体，背景替换为纯白。精度高、速度快，但需要分割服务已启动。
- **AI 生成**：使用 `generate_image` 以原图为参考图，由 AI 模型生成主体图。不依赖本地服务，但结果可能与原图有差异。

不确定用户意图时，一律先问。不要跳过此步骤直接选择一种模式。

## 本地分割模式

当用户选择"本地分割"时，按以下步骤执行：

### 步骤 1：生成主体蒙版

**优先使用工具调用**：
```
segment_subject(image="原图路径或制品ID")
```

**如果工具调用失败**（如"Server disconnected"），使用 API 直接调用：

```bash
# 1. 读取图片并转 base64
IMAGE_BASE64=$(base64 -w0 /path/to/image.jpg)

# 2. 调用分割接口
curl -X POST http://localhost:8001/segment \
  -H "Content-Type: application/json" \
  -d "{\"image\": \"data:image/jpeg;base64,${IMAGE_BASE64}\"}"
```

- 输入：原图路径或四位制品 ID
- 输出：`{"mask": "data:image/png;base64,..."}`
- 蒙版是黑白 PNG，白色=主体区域，黑色=背景区域
- 将 base64 解码保存为蒙版文件：`echo "<base64>" | base64 -d > mask.png`

### 步骤 2：主体提取

```
apply_mask(image="原图路径或制品ID", mask="上一步保存的蒙版路径")
```

- 输入：原图 + 蒙版路径
- 输出：干净主体图（纯白背景），自动注册为制品并发送给用户
- `background` 参数可选 `"white"`（默认）或 `"transparent"`

### 完成后

`apply_mask` 会自动：
1. 注册图片制品（分配制品 ID）
2. 发送制品 ID 通知给用户
3. 将图片文件发送给用户

**不需要额外调用 `message` 工具发送图片。** 直接告知用户提取完成即可。

### 分割服务不可用时

如果 `segment_subject` 工具不在可用工具列表中，或调用时报错"无法连接分割服务"：

1. 告知用户："分割服务不可用，已改用 AI 生成方式提取主体。"
2. 自动切换到 AI 生成模式执行（见下文）

## AI 生成模式

当用户选择"AI 生成"，或分割服务不可用自动 fallback 时：

```
generate_image(
  prompt="<根据用户需求和原图内容编写的描述性 prompt>",
  reference_images=["原图路径或制品ID"]
)
```

- prompt 由你根据用户意图和原图内容自行编写，或根据用户要求搜索合适的提示词
- prompt 应包含"提取主体、去除背景、输出纯白背景的主体图"等描述
- 生成后按 image-generation skill 的规则调用 `message` 工具发送图片给用户

## 制品引用

提取后的主体图会注册为图片制品（四位制品 ID，首位 1）。用户可在后续对话中引用此 ID：
- "用刚才提取的主体图生成一张新图" → 将制品 ID 作为 `generate_image` 的 `reference_images`
- "再做一次提取" → 将制品 ID 作为 `segment_subject` 或 `apply_mask` 的 `image` 参数
